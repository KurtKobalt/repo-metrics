# Engineering Pulse dashboard

React 19, TypeScript, Vite, Tailwind CSS, and Recharts power the OneVisa Engineering Pulse interface.

The app reads `public/metrics.json`, generated by `../scripts/metrics.py`. Run the collector before local development so person aliases and all fourteen configured repositories are available. Twelve repositories have organization remotes; `immi-scrapper` and `ov-agents` are collected from their local Git histories.

Every visualization follows the repository, person, and date filters. The comparison chart can group by person or repository and switch between commits and changed lines in weekly or accumulated mode. The contribution heatmap renders the complete selected history and can switch to a binary active/idle view; long ranges scroll horizontally on narrower screens. Hover or keyboard-focus a heatmap cell for a quick summary, then click or press Enter to open the full day timeline with hourly activity, repository line impact, contributors, and exact commits. A separate 24-hour cadence chart summarizes commit volume across the selected scope.

```bash
cd ..
python3 scripts/metrics.py
cd dashboard
npm run dev
```

Production output is written to `../site` for GitHub Pages.
